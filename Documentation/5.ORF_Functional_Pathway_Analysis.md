# Functional Genomics and Pathway Analysis of Predicted ORFs
## Overview of Functional Genomics and Pathway Analysis

**Functional genomics** aims to assign biological roles to predicted genes/ORFs by comparing them to curated databases, identifying protein families, domains, and functional categories. 

**Pathway analysis** further contextualizes annotated genes by mapping them to metabolic and signaling pathways. This enables the identification of biochemical capabilities, functional modules, and system-level interactions within an organism or microbial community.
Together, functional annotation and pathway analysis provide a comprehensive understanding of genome content, metabolic potential, and biological complexity.

## Scope of This Section

This section describes the computational workflow used to perform functional annotation and pathway analysis of predicted ORFs derived from assembled contigs. Specifically, it covers:

1. Functional annotation using the eggNOG-mapper platform

2. Data preprocessing, cleaning and summarization using Python

3. Quantitative assessment of annotation coverage

4. Visualization of functional categories, Pathways, Gene ontology terms and Protein domains.

## Tools, Software and Packages Used
### eggNOG-mapper

eggNOG-mapper is an orthology-based functional annotation tool that assigns gene functions by leveraging the eggNOG database of orthologous groups. It provides annotations including:

 - COG functional categories

 - Gene Ontology (GO) terms

 - KEGG Orthology (KO) identifiers and pathways

 - Pfam protein domains

eggNOG-mapper was selected due to its high accuracy, comprehensive database coverage and ability to generate multi-layer functional annotations suitable for downstream pathway and comparative analyses.

### Galaxy-US Server

The Galaxy-US web platform was used to run eggNOG-mapper without requiring local high-performance computing resources.

Galaxy provides a reproducible, user-friendly environment with standardized workflows and supports large biological datasets.

### Miniconda

Miniconda was used to manage Python environments and dependencies. It ensure reproducibility and prevent software version conflicts during data analysis.

#### Python and Associated Packages

The following Python packages were used:

**1. Pandas:** Data loading, manipulation, filtering and summarization

**2. Numpy:** Handling missing values and numerical operations

**3. Matplotlib and Seaborn:** Visualization of functional and pathway distributions

**4. Openpyxl:** Exporting results in Excel format

**5. Jupyter Notebook:** Interactive execution and documentation of analysis steps.

## Step-by-Step Computational Workflow
### 1. Conda Environment Setup
    conda --version
    conda create -n anno python=3.9 -y
    conda install pandas matplotlib seaborn jupyter openpyxl
    jupyter notebook

A dedicated Conda environment (anno) was created using Python 3.9 to ensure consistent software versions. Required libraries for data analysis and visualization were installed and Jupyter Notebook was launched for interactive analysis.

### 2. Importing Required Python Packages
    import pandas as pd
    import numpy as np
    import matplotlib.pyplot as plt

After activating the Conda environment and launching Jupyter Notebook, the required Python libraries were imported to enable data processing, numerical operations and visualization.

 - **pandas (pd)** was used for reading, filtering, cleaning, and summarizing the eggNOG-mapper annotation tables.

 - **numpy (np)** was used to handle missing values and perform basic numerical operations.

 - **matplotlib.** pyplot (plt) was used to generate publication-quality plots for functional and pathway analysis.

Importing these libraries at the beginning of the analysis ensures that all subsequent steps can be executed consistently within the same computational environment.

### 3. Counting Total Predicted ORFs
    orf_faa = "contigs_orfs.faa"

    with open(orf_faa) as f:
        total_orfs = sum(1 for line in f if line.startswith(">"))

    print("Total ORFs predicted from assembly:", total_orfs)

The FASTA file containing predicted ORFs was parsed and each header line (>) was counted to determine the total number of predicted ORFs. This value serves as a baseline for assessing annotation coverage.

### 4. Importing eggNOG-mapper Annotation Results
    anno_file = "Galaxy3-eggNOG Mapper_annotations.tabular"
    df = pd.read_csv(anno_file, sep="\t", comment="#")
    print("Total ORFs in eggNOG output:", df.shape[0])

The eggNOG-mapper output file was loaded into a pandas DataFrame and comment lines beginning with # were ignored. This step allows structured manipulation of annotation data.

### 5. Selection of Relevant Annotation Columns
    cols_keep = ["#query", "COG_category", "Description",
                "Preferred_name", "GOs", "KEGG_ko",
                "KEGG_Pathway", "KEGG_Module", "PFAMs"]

    df = df[cols_keep]
    df = df.replace("-", np.nan)

Only biologically relevant columns were retained for downstream analysis. Placeholder symbols (-) were replaced with missing values (NaN) to enable accurate filtering and counting.

### 6. Quantification of Annotation Types
    orfs_with_go = df["GOs"].notna().sum()
    orfs_with_kegg = df["KEGG_Pathway"].notna().sum()
    orfs_with_pfam = df["PFAMs"].notna().sum()
    both_go_kegg = df[df["GOs"].notna() & df["KEGG_Pathway"].notna()].shape[0]

This step quantifies how many ORFs are associated with GO terms, KEGG pathways, Pfam domains and combinations providing insight into annotation depth.

### 7. Removal of Completely Unannotated ORFs
    annotation_cols = ["COG_category", "Preferred_name", "GOs", "KEGG_ko", "PFAMs"]
    df_clean = df.dropna(subset=annotation_cols, how="all")

ORFs lacking all functional annotations were removed to generate a cleaned dataset containing only informative entries.

### 8. Export of Cleaned Annotation Data
    df_clean.to_excel("cleaned_annotation.xlsx", index=False)
    df_clean.to_csv("cleaned_annotation.tsv", sep="\t", index=False)

The cleaned annotation table was exported in both Excel and tab-delimited formats for downstream analysis, sharing and archival purposes.

### 9. Annotation Coverage Summary
    annotated_orfs = df_clean.shape[0]
    unannotated_orfs = total_orfs - annotated_orfs

    summary = pd.DataFrame({
        "Category": [
            "Total annotated ORFs",
            "ORFs with GO terms",
            "ORFs with KEGG pathways",
            "ORFs with Pfam domains",
            "ORFs with both GO and KEGG"
        ],
        "Count": [
            len(df),
            orfs_with_go,
            orfs_with_kegg,
            orfs_with_pfam,
            both_go_kegg
        ]
    })

A summary table was created to quantitatively describe the functional annotation landscape of the predicted ORFs.

## Data Visualization of Functional and Pathway Annotations

Graphical representation of functional annotation results is essential for identifying dominant biological functions, enriched pathways and conserved protein domains. In this study, bar plots and pie charts were generated using **matplotlib** to visualize the distribution of COG categories, KEGG pathways, Gene Ontology (GO) terms and Pfam domains among annotated ORFs.

### 1. Visualization of COG Functional Categories
    cog_counts = df_clean["COG_category"].value_counts()

    plt.figure(figsize=(8,5))
    cog_counts.plot(kind="bar")
    plt.xlabel("COG Category")
    plt.ylabel("Number of ORFs")
    plt.title("COG Functional Classification")
    plt.tight_layout()
    plt.savefig("COG_barplot.png", dpi=300)
    plt.show()


#### Explanation:

- The value_counts() function calculates the number of ORFs assigned to each COG functional category.

- A bar plot is generated to represent the distribution of ORFs across different functional classes.

- Axis labels and a descriptive title improve interpretability.

- The plot is saved at high resolution (300 dpi) for publication-quality output.

#### Biological relevance:

COG classification provides a broad overview of gene functions such as metabolism, information processing and cellular processes enables functional profiling of the dataset.

### 2. Visualization of KEGG Pathway Distribution
    kegg_counts = (
        df_clean["KEGG_Pathway"]
        .dropna()
        .str.split(",")
        .explode()
        .value_counts()
        .head(10)
    )

    plt.figure(figsize=(8,5))
    kegg_counts.plot(kind="bar")
    plt.xlabel("KEGG Pathway")
    plt.ylabel("Number of ORFs")
    plt.title("Top KEGG Pathways")
    plt.tight_layout()
    plt.savefig("KEGG_barplot.png", dpi=400)
    plt.show()

#### Explanation:

- ORFs without KEGG pathway assignments are removed using dropna().

- Multiple pathway annotations per ORF are separated using str.split() and expanded into individual rows using explode().

- The top 10 most frequently represented KEGG pathways are selected.

- A bar plot is generated to visualize pathway enrichment.

#### Biological relevance:

KEGG pathway analysis reveals dominant metabolic and signaling pathways providing insights into the metabolic potential and functional specialization of the organism or community.

### 3. Visualization of Gene Ontology (GO) Terms
    go_counts = (
        df_clean["GOs"]
        .dropna()

        .head(10)

    plt.figure(figsize=(8,5))

    plt.title("Top GO Terms")
    plt.tight_layout()
    plt.savefig("GO_barplot.png", dpi=300)
    plt.show()

#### Explanation:

- GO annotations are split into individual terms for each ORF.

- Frequency counts identify the most abundant GO terms.

- The top 10 GO terms are visualized using a bar plot.

#### Biological relevance:

GO term analysis provides a structured functional overview across molecular functions, biological processes and cellular components supporting functional interpretation at multiple biological levels.

### 4. Visualization of Pfam Domain Distribution
    pfam_counts = (
        df_clean["PFAMs"]
        .dropna()
        .str.split(",")
        .explode()
        .value_counts()
        .head(10)
    )

    plt.figure(figsize=(8,5))

    plt.xlabel("Pfam Domain")

    plt.title("Top Pfam Domains")
    plt.tight_layout()

    plt.show()

#### Explanation:

- Pfam domain annotations are separated and counted to identify frequently occurring protein domains.

- A pie chart is used to represent the proportional distribution of dominant domains.

- The figure is saved in high resolution for documentation and publication.

#### Biological relevance:

Pfam domain analysis highlights conserved structural and functional motifs, offering insights into protein families and evolutionary conservation.

The combination of bar plots and pie charts provides a comprehensive visual summary of functional annotations, enabling rapid identification of enriched functional categories, dominant pathways and conserved protein domains.
