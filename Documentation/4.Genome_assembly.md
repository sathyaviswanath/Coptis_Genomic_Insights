# De novo Genome Assembly and ORF Prediction
## Overview of Genome Assembly and ORF Prediction

Plant de novo genome assembly reconstructs a plant’s genome from scratch, using only raw sequencing reads without relying on an existing reference sequence. In this workflow, millions of short reads of Coptis are first quality‑checked and then assembled into longer contigs and scaffolds, which provide a first draft reference that can later be polished, evaluated, and annotated to study genes and traits in the plant.

## Scientific Context

**Raw Sequencing Data:** Public SRA dataset SRR12632749 (Illumina NovaSeq-WGS) from NCBI SRA.

**Reference Genome:** The genome assembly ASM1568090v1 for Coptis chinensis (accession GCA_015680905.1) from NCBI provides a haploid reference sequence for this medicinal plant.

## Scope of this Section

This section describes the steps used to assemble and analyze Coptis chinensis short‑read data against the reference genome assembly ASM1568090v1 using standard NGS tools.

## Step by Step Computational Workflow

### 1.Environment setup

    conda install -c conda-forge -c bioconda \
    fastqc fastq fastp multiqc spades quast bwa samtools seqtk emboss

Updates the conda environment and installs all required tools (FastQC, Fastp, SPAdes, QUAST, BWA, Samtools, Seqtk, EMBOSS) from the conda‑forge and Bioconda channels.
​
### 2.Directory creation and data download

    mkdir Raw_Data Output
    cd ./Raw_Data/

    wget -nc https://ftp.ncbi.nlm.nih.gov/genomes/all/GCA/015/680/905/GCA_015680905.1_ASM1568090v1/GCA_015680905.1_ASM1568090v1_cds_from_genomic.fna.gz
    wget -nc https://ftp.ncbi.nlm.nih.gov/genomes/all/GCA/015/680/905/GCA_015680905.1_ASM1568090v1/GCA_015680905.1_ASM1568090v1_genomic.gff.gz

    wget -nc ftp.sra.ebi.ac.uk/vol1/fastq/SRR126/249/SRR12632749/SRR12632749_1.fastq.gz
    wget -nc ftp.sra.ebi.ac.uk/vol1/fastq/SRR126/249/SRR12632749/SRR12632749_2.fastq.gz

Creates Raw_Data and Output directories, moves into Raw_Data and downloads the Coptis chinensis reference CDS and GFF files plus paired‑end reads SRR12632749 from ENA/NCBI.
​
### 3.Read subsampling

    seqtk sample -s 123 ./SRR12632749_1.fastq.gz 300000 > SRR12632749_1_300k.fastq
    seqtk sample -s 123 ./SRR12632749_2.fastq.gz 300000 > SRR12632749_2_300k.fastq

    rm SRR12632749_1.fastq.gz SRR12632749_2.fastq.gz

Uses Seqtk to subsample first 300,000 reads from each FASTQ file with a fixed seed for reproducibility, then removes the larger original files to save disk space.

### 4.Quality control

    fastqc -o ../Output/ ./SRR12632749_1_300k.fastq ./SRR12632749_2_300k.fastq

Runs FastQC on the subsampled paired‑end reads to generate per‑sample HTML and ZIP reports summarizing base quality, GC content, adapter contamination and other metrics, saving all reports in a Output directory

### 5.Genome assembly

    spades.py \
    -1 ./SRR12632749_1_300k.fastq \
    -2 ./SRR12632749_2_300k.fastq \
    -o ../Output/ --careful -t 4 -m 16

Runs SPAdes to perform de novo assembly of the paired‑end reads, writing contigs and scaffolds into the Output directory while using the --careful option, 4 threads, and 16 GB of RAM.

### 6.Assembly quality assessment

    cd ../Output/
    mkdir Assembly_QC

    quast.py ./contigs.fasta \
    -r ../Raw_Data/GCA_015680905.1_ASM1568090v1_cds_from_genomic.fna.gz \
    -o ./Assembly_QC/ -t 2

Creates an Assembly_QC directory and runs QUAST to compare the assembled contigs to the Coptis chinensis reference CDS file, generating standard assembly statistics (N50, total length, misassemblies, etc.).
​
### 7.ORF prediction

    mkdir ORF
    getorf -sequence ./contigs.fasta \
        -outseq ./ORF/contigs_orfs.faa \
        -minsize 300 -find 1

Creates an ORF directory and uses EMBOSS getorf to scan the contigs for open reading frames of at least 300 bp in the forward direction, exporting predicted protein sequences in FASTA format for downstream functional analysis.
